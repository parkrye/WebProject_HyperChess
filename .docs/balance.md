# HyperChess 밸런스 기록

능력 수치와 측정 결과를 **버전별로 계속 쌓는** 문서. 최신 버전이 위에 온다.

- 코드상 수치: `packages/engine/src/abilities/balance.ts` (이 파일에서만 조정)
- 능력 규칙: [rules.md](rules.md)
- 측정 도구: 루트 `balance.bat` (사용법은 README "밸런스 측정")

## 기록 규칙

새 버전을 추가할 때 아래 항목을 채운다.

1. **변경**: 규칙 변경과 수치 변경분 (이전 버전 대비)
2. **측정 조건**: 방식(지정 상대/리그전), 판 수, 탐색 깊이, AI 버전
3. **결과**: 도구가 만든 보고서(`reports/`)의 표를 옮긴다
4. **판단**: 무엇이 과하거나 약한지, 다음 조정 후보

부분 재측정: 일부 능력만 바꿨다면 리그전에서 그 능력이 낀 대진만 새로 두고 나머지는 직전 버전 결과를 합산한다 (`--focus`, `--base`). 이 경우 표에 "재측정" 여부를 표시한다.

목표: **능력끼리 대결 승률 50% 전후**. **시간 역행은 밸런스 예외 항목**으로 v13부터 측정에서 제외한다(표에는 "-"). v11부터 리그전에서 "능력 없음"을 빼고 측정한다 (능력 없음이 섞이면 능력들의 점수율이 부풀려짐).

측정값 해석 시 주의:
- 오차(95% 신뢰구간)는 판 수 n일 때 대략 ±100/√n %p다. 24판 ±20%p, 88판 ±10%p, 120판 ±9%p.
- AI가 능력을 쓰는 실력이 결과에 섞여 있다. 사람의 체감 강도와 다를 수 있다.
- **AI 버전이 바뀌면 이전 결과와 직접 비교하지 않는다.** (v1~v4: AI v1, v5~: AI v2)
